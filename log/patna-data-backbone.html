A data backbone for a large organisation

Led the data and tech department from setup: built the JS Vahini mobile app, websites, 50+ MySQL tables, automated outreach and 3 large ML models.

WhenMar 2024 – Nov 2024
WherePatna
StatusDelivered

The situation

At Jan Suraaj in Bihar I set up and led the data and technology department as a consultant, starting from the baseline. The organisation was large, fast-growing and spread across the state, and it needed one reliable picture of its people and activity.

What I did

  • Set up the data and tech department from scratch and led the team that ran it.
  • Built the JS Vahini mobile application and led its team from the first setup.
  • Shipped multiple websites, mobile apps and databases for the organisation.
  • Designed the data model and built 50+ MySQL tables.
  • Automated outreach at scale across calls, WhatsApp and IVR.
  • Developed 3 large machine learning models, including a volunteer-matching model.
  • Built a single portal that joined telephony, WhatsApp and AI-IVR.
  • Built onboarding workflows for new volunteers.
  • Set up a CATI and CAPI command centre with dashboards and quality-control reporting.

By the numbers

50+database tables

What I carried forward

Here I learned to design for an organisation, not a project: shared IDs, clean ownership of data and dashboards that people actually open.
